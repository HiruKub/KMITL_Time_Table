# KMITL Time Table (Browser Extension)

A browser extension designed to help students at King Mongkut's Institute of Technology Ladkrabang (KMITL) view and manage their class schedules more conveniently.

## Step 1: Prepare the Files

1. Download the project `.zip` file to your computer.
2. Extract (unzip) the downloaded archive.
3. Open the extracted folder and ensure that the `manifest.json` file is directly inside it. (If extracting creates nested folders, select the innermost folder containing `manifest.json`).

> **Note:** Do not delete or move the extracted folder after installation, as doing so will break or remove the extension from your browser.

## Step 2: Browser Installation

### 1. Google Chrome
1. Open Google Chrome and enter the following address in the URL bar:
   ```text
   chrome://extensions/
   ```
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked** in the top-left corner.
4. Select the extracted folder containing `manifest.json` and click **Select Folder**.

### 2. Microsoft Edge
1. Open Microsoft Edge and enter the following address in the URL bar:
   ```text
   edge://extensions/
   ```
2. Toggle on **Developer mode** in the left sidebar (or bottom-left corner).
3. Click **Load unpacked**.
4. Select the extracted folder containing `manifest.json` and click **Select Folder**.

### 3. Brave
1. Open Brave and enter the following address in the URL bar:
   ```text
   brave://extensions/
   ```
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked** in the top-left corner.
4. Select the extracted folder containing `manifest.json` and click **Select Folder**.

### 4. Opera / Opera GX
1. Open Opera and enter the following address in the URL bar:
   ```text
   opera://extensions/
   ```
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked** in the top-left corner.
4. Select the extracted folder containing `manifest.json` and click **Select Folder**.

### 5. Mozilla Firefox (Temporary Installation)
1. Open Firefox and enter the following address in the URL bar:
   ```text
   about:debugging#/runtime/this-firefox
   ```
2. Click **Load Temporary Add-on...**
3. Navigate to the extracted folder, select the **`manifest.json`** file, and click **Open**.

> **Note for Firefox:** This method installs the extension temporarily. It will be removed when you close Firefox and must be reloaded the next time you open the browser.

## Step 3: Getting Started

1. Click the **Extensions** icon in the top-right toolbar of your browser.
2. **Pin** **KMITL Time Table** so the icon remains visible on your toolbar.
3. Visit the KMITL Registrar website (Reg KMITL) and refresh the page, or click the extension icon to view your schedule.
